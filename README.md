Tech-kaze-No

Tech-kaze-No is an Android application developed during a hackathon. The main goal of the application is to provide users with a simple and discreet way to send an emergency alert to trusted people when they are in a potentially dangerous situation.

The application continuously monitors the user's location and uses voice commands to trigger an emergency signal. When the predefined command is detected, the application sends an alert containing the user's current location to their selected close contacts, allowing them to quickly respond and provide assistance.

Features
📍 Real-time user location tracking
🎙️ Voice command for triggering an emergency alert
🚨 Automatic emergency signal to trusted contacts
👥 Management of close/emergency contacts
🗺️ Sharing the user's current location with contacts

The project was developed as part of the Tech-kaze-No hackathon, with a focus on using mobile technology to provide a fast and accessible personal safety solution.
